# 🇰🇷 한국사 국가 실전 시험 교구재 개발 (한능검 심화 7급 합격 올인원 CBT)

> **국사편찬위원회 공식 기출 빅데이터 기반 | 77개 불변의 출제 공식 | 실전 1:1 CBT 문제은행 프로그램**

본 프로젝트는 **한국사능력검정시험(한능검) 심화 1·2급 및 7급 공무원 한국사 대체 시험**을 준비하는 모든 수험생들이 가장 빠르고 정확하게 합격선(70점~100점)을 돌파할 수 있도록 기획·개발된 **국가 실전 시험 맞춤형 디지털 교구재**입니다.

## 🌟 핵심 특징 (Why This Project?)

1. **국사편찬위원회 기출 100% 반영 요약사료 원문 수록**
   - 단순 암기용 키워드 나열이 아닌, 『사기』, 『삼국사기』, 『고려사』, 『조선왕조실록』 등 실제 시험지에 인쇄되는 **줄글 사료 원문**을 탑재하여 실전 사료 독해력을 기를 수 있습니다.
2. **단 77개로 압축한 정답 연결 공식'**
   - 역대 60회~70회대 기출 빅데이터에서 매회 95% 이상 토씨 하나 안 틀리고 반복 출제되는 핵심 족보(기본 63문항 + 킬러 14문항)를 엄선하였습니다.
3. **새 탭 낭비 0% / 무설치 단일 웹 앱(One-Tab CBT)**
   - 브라우저 창 1개 안에서 엑셀 요약 표와 4지선다 기출 문제를 동시에 보며 풀 수 있는 **올인원 일체형 스터디 뷰어**를 지원합니다.
4. **1초 컷 해설 & 튜터 암기 공식 제공**
   - 문제를 풀자마자 정답 선지와 사료 속 결정적 단서, 튜터만의 직관적인 앞글자 암기 팁이 즉각 펼쳐집니다.

## 🚀 초간단 사용 방법 (Quick Start)

### 방법 ①: 웹 브라우저로 바로 풀기 (가장 추천 ⭐⭐⭐)
1. **`cbt_player.html`** 파일을 더블클릭합니다. (크롬, 웨일, 엣지 등 모든 브라우저 지원)
2. 상단 모드 선택:
   - **`1문제 집중 모드`** : 실제 CBT 시험장처럼 화면에 문제 1개씩 크게 띄워 풀기
   - **`📑 엑셀 표 함께보기 (새창 0%)`** : 화면 상단에 엑셀 족보 표를 띄워두고, 원하는 문제를 클릭하여 아래에서 즉시 풀기
   - **`전체 모아보기`** : 77개 전체 문제를 한 페이지에서 쭉 훑어보기
3. 우측 **`[OMR 빠른 번호판 (Q1~Q77)]`**을 누르면 원하는 문제로 0.01초 만에 즉시 전환됩니다.
4. **키보드 단축키 지원**:
   - `[←] / [→]` : 이전 문제 / 다음 문제 이동
   - `숫자 1, 2, 3, 4` : 보기 선택 및 즉각 채점

---

### 방법 ②: 엑셀 족보와 함께 공부하기
1. **`한국사 능력 검정 심화 7급 공무원 준비.xlsx`** 파일을 엽니다.
2. 원하는 시대 시트(선사, 삼국, 고려, 조선, 근대, 일제, 현대, ★킬러_Red)를 선택합니다.
3. [사료 필수 키워드] ➜ [정답 연결 선지] ➜ [암기 팁]을 학습한 후, **I열의 `[📝 Qxx번 CBT 풀기]`**를 클릭하여 브라우저에서 바로 실전 문제를 풀어봅니다.

## 🎯 목표 점수별 합격 커리큘럼

* **7급 공무원 자격 요건 (한능검 심화 2급, 70점 이상 목표)**:
  - 교구재에 수록된 1번~62번(기본 뼈대)만 구구단처럼 암기 후 CBT 1회독 완료 ➜ **무조건 75~82점 합격**
* **100점 만점 / 1급 안정권 (80점~100점 목표)**:
  - 기본 62문항 + **`★킬러_100점완성_공식(Red)`** 시트의 탑/불상 사진, 단골 지역사, 고난도 순서 나열 15개 테마까지 완벽 정복 ➜ **92점~100점 돌파**
